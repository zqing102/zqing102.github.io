使用说明

本页面负责资料整理与任务管理；真正打开浏览器自动填表由本机版完成。

四步流程

  1. 整理资料在「我的资料」填写或导入简历，核对后保存在本机浏览器。
  2. 添加网站在「招聘任务」粘贴招聘网址，形成清单。
  3. 本机填写在电脑上启动本机版，打开真实浏览器登录并批量扫描、填写。
  4. 人工提交逐站核对内容，由你本人点击最终提交。工具不会自动投递。

启动本机版

自动填表需要操作你电脑上的浏览器，因此必须在自己的设备上运行，不能在公网服务器上完成。

python -m pip install -r requirements.txt
python -m playwright install chromium
python run.py

Windows 可直接双击 start.bat。启动后打开 http://127.0.0.1:8765，端口冲突时使用 python run.py --port 8766。

关于数据

  • 本页面使用浏览器 localStorage 保存资料和清单，数据只在你当前的浏览器里。
  • 点击「导出 JSON」可获得与本机版兼容的档案文件，可随时备份或迁移。
  • 换浏览器或清除站点数据会丢失内容，建议定期导出备份。
  • 可导出的档案包含个人信息，请勿上传到公共网盘或分享给他人。
