EXTENSION

三步开始

Manifest V3
  1. 加载Chrome 打开 chrome://extensions，开启右上角「开发者模式」，点击「加载已解压的扩展程序」，选择项目里的 extension 目录。
  2. 配对启动本机版服务后，在任意招聘页面点开扩展图标，点一次「连接本机服务」。扩展会自动申请配对令牌，服务不在默认端口时也可手动粘贴。
  3. 扫描填写点「扫描页面」→ 勾选要填的字段 →「填写勾选字段」。核对页面高亮后，自己点击提交。

置信度分档

≥0.85 / 0.6–0.85 / <0.6

每个字段按匹配置信度分三档，填写后直接在页面上用描边标出来，右下角有图例说明：

已填写识别明确，直接写入 待确认部分匹配，已写入但请核对 需人工未识别或属于敏感字段，不填

识别不到的控件、日期精度不足、复杂级联选择，以及密码、验证码、证件号、薪酬和条款勾选，都会落到「需人工」，而不是猜一个值填进去。

不会替你做的事

  • 不点击提交、投递、申请、Apply 类按钮；填写期间拦截页面的自动 submit / requestSubmit。
  • 不自动登录：检测到密码框或验证码就暂停并提示，由你先完成登录。
  • 不跨源扫描：跨源框架会被列出来，但无法识别其中的字段，需要人工填写。
  • 不把「填完」记成「已投递」：投递状态只由你手动标记，重新扫描也不会改回去。
  • 不上传资料：扩展只取填写所需的字段值，不向招聘网站或任何第三方发送完整档案。
自动填写结束后，请在页面里检查所有内容，由你亲自点击最终提交。

重复经历怎么补

多条经历不够时点「补齐重复经历」：只会点击名称以「添加 / 新增」开头的按钮，点完自动重新扫描。新出现的空行不会沿用上一行的数据——资料里没有那一条，就保持空白等人来填。

页面在填写中途新增字段时，扩展会提示「页面结构已变化」，建议重新扫描后再填写，避免按旧结构操作。

完整流程。

本页负责资料整理与任务管理；真正打开浏览器自动填表，由「浏览器扩展」或「本机工作台」在你的电脑上完成。

四步流程

  1. 整理资料在「我的资料」填写或导入简历，核对后导出成与本机版兼容的档案 JSON。
  2. 建立清单在「招聘任务」粘贴招聘网址，记录企业、岗位与填写进度。
  3. 扫描填写两条路二选一：加载「浏览器扩展」在自己打开的招聘页面上逐页填写；或启动本机工作台批量处理多个网站。
  4. 人工提交逐站核对内容，由你本人点击最终提交。工具不会自动投递，也不会把「填完」记成「已投递」。

启动本机版

扩展与工作台都需要操作你电脑上的浏览器，因此必须在自己的设备上运行，不能在公网服务器上完成。

python -m pip install -r requirements.txt
python -m playwright install chromium
python run.py

Windows 可直接双击 start.bat。启动后打开 http://127.0.0.1:8765，端口冲突时使用 python run.py --port 8766。只用浏览器扩展时不需要安装 Playwright 浏览器，本机工作台的批量填写才需要。

关于数据

  • 本页使用浏览器 localStorage 保存资料和清单，数据只在你当前的浏览器里。
  • 点击「导出个人档案」可获得与本机版兼容的 JSON 文件，可随时备份或迁移。
  • 换浏览器或清除站点数据会丢失内容，建议定期导出备份。
  • 导出的档案包含个人信息，请勿上传到公共网盘或分享给他人。
